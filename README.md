# Lifeplus PDF Suiza · Schweiz

Catálogo independiente para `lifepluspdfch.peterestela.com` con fichas de producto Lifeplus en español y alemán.

- 128 productos con ficha en español.
- 96 productos con ficha oficial en alemán.
- Buscador y filtros por disponibilidad de idioma.
- Enlaces directos verificados a los productos disponibles en la tienda suiza `SHX4C7` de Lifeplus.
- Nunca se utiliza el catálogo general como sustituto: si no existe una ficha de compra concreta, se muestra que el producto no está disponible.
- Los productos comprables aparecen primero para que sus botones directos sean visibles al abrir el catálogo.
- El catálogo también se distribuye como JavaScript para que Chrome pueda abrir `index.html` directamente mediante `file://` sin bloquear los datos, productos o imágenes.

La web original `lifepluspdf.peterestela.com` no forma parte de este repositorio y no se modifica.
